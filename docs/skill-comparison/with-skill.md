## Not covered
- AC1, Exception: no separate case. The unexpected events around saving (double-click, lost connection, expired session) are tested once under AC3 rather than repeated for each Case Origin.
- AC2, Negative: the story does not say whether Status or Priority may be left empty or which values are allowed, so there is no rule to break yet (see Questions).
- AC3, boundary beyond eight digits: what happens after Case Number 99999999 is not tested, because it cannot be reached by hand and the story does not define it.
- AC5, escalating a case that is already Escalated or already closed: the story does not say which starting statuses can be escalated.
- AC6, deleting from anywhere other than the record page (for example a row menu in the Cases list): the story does not say where Delete is offered.
- Permissions: whether users other than support agents can create, escalate or delete cases is outside this story.
- No Low priority cases: without agreed message wording and layout there is nothing cosmetic to check yet.

## Questions for the BA
- What are the exact texts of the required-field error on Case Origin, the save confirmation, and the delete confirmation dialog (title, message and button labels)?
- Besides Subject, which fields does the New Case form have, and are any required other than Case Origin? The test data assumes an optional Subject field exists.
- Which Status and Priority values are available? TC-CASE-006 assumes "Working" and "High" exist. Can a case be created directly with Status "Escalated" (TC-CASE-016 selects it before cancelling)?
- Can Status or Priority be cleared, and if so what should happen on Save?
- Is Case Origin empty by default, or pre-selected?
- AC3: must Case Numbers be consecutive, or only unique? Is the number shown inside the confirmation message, on the record page, or both?
- AC3: when the connection drops or the session expires on Save, should the entered data be kept so the agent can retry?
- AC4: should Cancel, X, Esc or browser Back warn about unsaved changes before closing, or close immediately?
- AC5: can a case be escalated from any Status, including a closed one? Does escalation require a reason or trigger anything else (notification, reassignment)? Is editing Status in place on the record page allowed as well as through Edit?
- AC5: when two agents save changes to the same case, which change wins and what is the second agent shown?
- AC6: can a deleted case be restored, and can any agent delete any case or only their own?
