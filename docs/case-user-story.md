# User story: Log a customer problem as a case

**As a** support agent
**I want to** record a customer's problem as a case
**So that** it is tracked until it is resolved

## Acceptance criteria

1. A case cannot be saved without a Case Origin (Phone, Email or Web).
2. A new case starts with Status New and Priority Medium unless the agent changes them.
3. Saving a case shows a confirmation and gives the case an eight-digit Case Number.
4. Cancelling the form creates nothing.
5. An agent can escalate a case from its record page by changing Status to Escalated.
6. Deleting a case asks for confirmation first.
