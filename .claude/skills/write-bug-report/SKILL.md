# Our bug report format

- **Title**: what is wrong and where, in one line (`Incident form accepts a future date`).
- **Environment**: application, version or build, browser.
- **Steps to reproduce**: numbered, one action each, with the exact data entered.
- **Expected result** and **Actual result**: always both, one sentence each.
- **Severity**: Critical, High, Medium or Low. Say why in a few words.
- Leave out guesses about the cause unless asked.
